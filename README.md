# Excel Cell Navigator 🎯

An interactive browser-based game to teach students how to identify and name Excel cells (e.g., A1, B3, F6).

## Features
- 📖 **Exploration Mode** — hover over cells to learn their coordinates with visual and audio feedback
- 🎯 **Challenge Mode** — find the target cell within 12 seconds across 3 stages
- 🔊 Sound effects for hover, click, win, and fail
- ❤️ One-life system to keep students focused
- 📱 Fully responsive — works on mobile and desktop
- 👤 "Next Student" button to instantly reset for classroom use

## How to Use
1. Open `خلايا_الاكسل.html` in any browser
2. Start with **Exploration Mode** to familiarize students with the grid
3. Switch to **Challenge Mode** for a timed quiz
4. Press **Next Student** after each round to reset

## Tech Stack
- Pure HTML / CSS / JavaScript
- No external libraries or dependencies
- Web Audio API for sound effects

## Classroom Tips
- Use on a projector for group competition
- Let students race against the timer individually
- Great warm-up activity before Excel lessons
